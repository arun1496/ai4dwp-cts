# L1 Help: New Device Setup Fails Because Device Was Already Set Up Before

v 1.0, 11/08/2026, status : Draft

If your Windows setup stops and does not finish, your access and files are safe. This issue can happen when the device still has an old setup record from a previous setup.

## What you can do now

1. Restart the device once.
After restart, try setup again.

2. If setup fails again, stop after the second try.
Do not keep retrying.

3. Contact Service Desk.
Share the device name and the time setup failed.

## Important

- Your data is safe. This is a setup control issue, not data loss.
- Repeating setup many times does not fix this and may delay recovery.

## Contact the service desk if...

Contact the service desk if setup fails more than once, shows an error code, or returns to the same setup screen repeatedly.

## Details to include in your support request

- Your full name
- Your work login name or email
- Device name (if visible)
- Time the failure happened
- What screen or message you saw
- Whether a restart was already tried
